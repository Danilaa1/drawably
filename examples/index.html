scrawl

Hand-drawn UI. Fresh pen sketch every mount.

Every stroke is generated at load. Hover a control to re-sketch.

Install

API

Attach SVG chrome to a real control. Omit seed for a unique sketch per mount.

  • scrawlButton(el, opts)outline · solid · scribble
  • scrawlCheckbox(wrap, opts)wraps a checkbox
  • scrawlInput(wrap, opts)wraps an input
  • scrawlCard(el, opts)sketched container 
import { scrawlButton } from "scrawl";
import "scrawl/style.css";

scrawlButton(done, { variant: "solid" });
